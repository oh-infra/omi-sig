# Oh My Infra Bootstrap Working Group

Oh My Infra Bootstrap Working Group（OMI BWG）是格维开源社区和华科开放原子开源俱乐部共同发起的 Oh My Infra 启动工作组。

Oh My Infra 起源于 QEMU Camp。在持续的训练营实践中，我们逐步从 QEMU、模拟器与虚拟化技术出发，将学习和实践范围延伸到操作系统、编译器、云原生、AI Infra 等更广泛的基础软件与系统基础设施方向。

OMI BWG 将负责 Oh My Infra 的整体规划与社区启动，包括技术方向、课程体系、实践项目、导师协作以及社区运行机制建设。我们希望延续 QEMU Camp 免费开放、资料开源、社区共建、面向真实项目实践的理念，将 Oh My Infra 建设成为一个由开发者共同参与、持续演进的开源 Infra 技术学习与实践社区。
